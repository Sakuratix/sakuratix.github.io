02 / подход

      
Как код попадает в прод.

      
Каждый коммит проходит один и тот же путь. Ручных шагов в нём — ноль, кроме кнопки «в прод».

      

        

        
01
Commit
Ветка, MR, ревью. Pre-commit хуки и линтеры.

        
02
Build
Многоступенчатый Dockerfile, кэш слоёв. gitlab-ci

        
03
Test & scan
Тесты, trivy, hadolint, tflint.

        
04
Release
Образ с тегом коммита в registry, Helm-чарт с версией.

        
05
Deploy
Helm / Argo CD в dev → stage → prod. Rollback одной командой.

        
06
Observe
Prometheus, Grafana, Loki. Алерты в Telegram.

Sakuratix/infra-lab↗

          
infra-lab

          
Путь сервиса от кода до прода в одном репозитории: Docker, Helm, Terraform, Ansible, CI и мониторинг.


infra-lab/
├── app/            # Python-сервис + /metrics
├── helm/app/       # чарт: probes, HPA, ingress
├── terraform/      # Yandex Cloud: VPC, k8s, PG
├── ansible/        # харденинг + node_exporter
├── monitoring/     # prometheus · grafana
└── .github/workflows/

Портфолио

          
Один HTML-файл без сборщика, WebGL на three.js. Деплой в GitHub Pages через GitHub Actions на каждый пуш в main.


on: push → main
jobs:
  deploy:
    - actions/checkout
    - actions/upload-pages-artifact
    - actions/deploy-pages   # ✓ 14s
